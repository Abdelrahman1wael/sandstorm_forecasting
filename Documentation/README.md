# 📚 Sandstorm Forecasting: Documentation Hub

This directory contains research publications, dataset audits, scientific methodology guides, presentation materials, and literature references for the Riyadh Sandstorm Forecasting project.

```
Documentation/
│
├── dataset_reports/        # Rigorous dataset audit reports, provenance verification & taxonomy
├── manuscripts/            # Research papers, thesis proposals, and draft revisions
│   ├── final/              # Consolidated final manuscripts & rewritten versions
│   └── drafts/             # Working drafts, proposals, and backup revisions
├── presentation/           # Midterm/defense slides scripts, speeches & highlighted review notes
└── literature_and_refs/    # Benchmark scientific papers (PDFs), references JSON & literature CSV
```

## 📂 Section Directory Inventory

### 1. `dataset_reports/`
Scientific audits and metadata guides governing dataset integrity and physical corridor modeling:
* **`RIYADH_DATASET_AUDIT_AND_CRITIQUE_REPORT.md`**: Foundational audit diagnosing the 53.7 artifact, simulated AERONET data, and physical corridor definitions.
* **`RIYADH_AND_CONNECTED_DESERTS_DATASET_GUIDE.md`**: Guide to the 5 desert systems (Al-Thumamah, Ad-Dahna, Nafud al-Thuwairat, Tuwayq, Rub' al-Khali) and station bearings.
* **`RIYADH_REAL_DATASETS_PROVENANCE_AND_VERIFICATION.docx`**: Official dataset verification document detailing NOAA/METAR, ERA5, and satellite download provenance.
* **`Sandstorm_Forecasting_Taxonomy_and_Methodology.docx`**: Full taxonomy and methodological specifications for Line A and Line B models.
* **`Data_for_SandStorm_Forecasting.docx`**: Data acquisition requirements and station inventory.
* **`Riyadh_Selection_Rationale.docx`**: Climatological and demographic rationale for focusing on the Riyadh metropolitan basin.
